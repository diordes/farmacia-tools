⚙️ Configuració

Google Cloud OAuth

Necessites un projecte a Google Cloud Console amb Gmail API i Drive API activades, i un OAuth Client ID per a aplicació web.

Comptes Gmail

Connecta un o més comptes de Gmail. Cada compte tindrà accés a Gmail i Drive.

Fonts externes (webs)

Afegeix webs de proveïdors per buscar factures (Amazon, portals de proveïdors, etc.). Per a webs externes, puja els PDFs manualment o configura l'accés.

Carpeta Drive destí

Selecciona un compte connectat. Totes les factures (de qualsevol Gmail) es pujaran a aquest Drive.

{YEAR} es substitueix automàticament per l'any actual (2026, 2027...)

Historial de duplicats

L'eina recorda les factures ja processades per no repetir-les. Si vols tornar a escanejar-ho tot de nou, esborra l'historial.

Proveïdors coneguts

Mapa email → nom proveïdor. Es fa servir per normalitzar noms als fitxers.
